# Foundvia Discovery coordinator

Start with `foundvia-discovery` for a public-site audit, practical fixes, launch experiment, or measurement. Use one focused module only when its specialty helps the user's request. The flagship is self-contained and does not need delegation to other agents.

| Request | Module |
|---|---|
| Early Google/ChatGPT discovery | foundvia-discovery |
| AI search eligibility or crawler policy | seo-ai-geo |
| Inaccurate or synthetic content dates | seo-slug-dates |
| Technical rendering/performance | seo-technical |
| Metadata/headings/links | seo-on-page |
| Content strategy | seo-content-strategy |
| Location-based business | seo-local |
| Analytics investigation | seo-analytics |
| Content/distribution at scale | seo-growth-engine |
| Next.js code helpers | seo-nextjs-implementation |
| Explicit squirrelscan audit | seo-audit-website |

Read the [review status](../README.md#advanced-modules). Several legacy references are not fully reviewed. Corrected primary-source guidance outranks historical snippets: do not generate fake dates, conflate search/training crawlers, require llms.txt, or promise FAQ rich results.

Respect the user's scope and existing authorization. External publishing, production changes, and paid services require authorization for those actions. Report observations, concrete fixes, validation, and remaining limitations clearly.
