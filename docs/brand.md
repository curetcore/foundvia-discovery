## Visual system

Direction: editorial, technical and calm. The signature is the authentic logo, large language a founder understands, and a visible path from evidence to verification.

| Token | Value | Purpose |
|---|---|---|
| Background | `#09090b` | Cover canvas |
| Surface | `#18181b` | Supporting report panels |
| Border | `#3f3f46` | Quiet separation |
| Primary text | `#fafafa` | Headline |
| Supporting text | `#a1a1aa` | Secondary copy |
| Accent | `#fb4b3e` | Proposed editorial accent; original flame colors unchanged |

These are proposed toolkit tokens, not a claim that every value is a production CSS token. State colors require written labels and appear in reports, not as decoration. Use Geist for graphic copy where available, with its licensing checked before distributing font files. GitHub controls Markdown typography. The local preview uses the installed font; it is not part of the public brand asset pack.

Cover: 1200 × 760, 64 px margins, 8 px spacing grid, headline 112 px / 1.02, logo 240 px wide, project label 24 px, supporting line 30 px. At 320 px image width the headline remains approximately 30 px. Important details remain outside the image in Markdown. Social preview is a separate composition in O5, not a crop that truncates this cover.

Avoid miniature terminal windows in the cover, provider-logo walls, invented metrics, glow effects, decorative dashboards and repeated cards. Reports and diagrams must explain observed behavior. Retain editable sources and raster exports.
