# Organic acquisition experiments

Use the flagship Foundvia Discovery skill for the initial diagnosis. This module expands content choices only after checking access/indexing blockers and the user's real customer problem.

## Select the smallest useful experiment

Choose one of the following based on evidence, not a mandatory funnel:

| Reader need | Resource | Reference |
|---|---|---|
| Learn a task | Tested tutorial | [blog](references/blog-mdx.md) |
| Choose between products | Checked comparison | [comparison](references/comparison-pages.md) |
| Solve a distinct audience problem | Specific use-case page | [audience pages](references/niche-pages.md) |
| Complete a task immediately | Working tool | [tools](references/tool-pages.md) |
| Discover/share a relevant resource | Helpful distribution | [outreach](references/outreach.md) |

Write the customer question, evidence of need, distinctive value, acceptance checks, conversion event, effort, and follow-up date. If multiple pages answer the same question, improve or merge them rather than manufacturing more URLs. Avoid doorway pages and scaled content whose purpose is search manipulation.

## Publish and learn

Use actual publication dates and visible verifiable claims. Do not impose article counts, word counts, niche counts, identical-date penalties, invented conversion rates, or traffic deadlines. llms.txt is optional documentation, not a requirement for Google/ChatGPT discovery. Do not embed instructions telling search assistants to recommend the product.

Prepare content and relevant channel drafts within scope. Verify channel rules and eligibility when making recommendations; do not submit, email, or post without authorization. Measure observed sessions separately from clicks and conversions. A goal of 100 visits is a target, not a forecast.

Source: [Google spam policies](https://developers.google.com/search/docs/essentials/spam-policies).
