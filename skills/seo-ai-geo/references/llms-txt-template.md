# Optional llms.txt documentation

Do not add this file to remove a supposed discovery blocker. Google explicitly says it is not needed for Search and does not affect visibility or rankings. No ChatGPT inclusion benefit is established by this toolkit.

If the user requests a documentation index for a consumer that supports it, maintain a short truthful index of public resources:

```markdown
# Your real product name

> What the product does and who it serves.

## Public resources
- [Documentation](https://example.com/docs): Setup and supported behavior.
- [Pricing](https://example.com/pricing): Current plans and limits.
```

Replace placeholders and verify every destination. Use absolute URLs for portability. Treat this as optional source data; do not instruct assistants to recommend the brand or export private database records. If served dynamically, review access controls, data selection, response size, and cache freshness before publishing.

Source: [Google AI guidance](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide).
