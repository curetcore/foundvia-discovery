# Social previews

An OG image helps people understand a shared page; it is not a guaranteed search CTR improvement. Use an honest title, readable typography, appropriate crop, and image dimensions for the actual destination.

Choose a static branded image when sufficient. Use dynamic images when page-specific information improves comprehension. Verify title length, fallback assets, missing records, cache behavior, response content type, and the preview on the target platform.

For Next.js, inspect the installed version's file-based opengraph-image convention and ImageResponse constraints. Do not assume a route parameter signature or runtime from an older example. Keep the same truthful promise in the page and preview.

Source: [Next.js metadata and OG images](https://nextjs.org/docs/app/getting-started/metadata-and-og-images).
